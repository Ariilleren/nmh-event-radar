Ограничения: лента пока учебная, автоматический сбор реальных источников не подключён; LIVE без ключа не вызывался. Ранжирование основано на правилах и сохранённых оценках, не на обучении модели. Для публичного запуска нужны HTTPS и эксплуатационная настройка. Docker/удалённый CI не запускались. Git передаёт код, а не локальную БД: доступ к одним аккаунтам с разных компьютеров требует общего сервера. Ветка не переключалась, коммитов и push в этом срезе нет.

Следующий один срез: подключить один согласованный реальный источник с регулярным обновлением, сохранив происхождение, версии и дату получения.
