# AI: режимы и проверка подключения

DEMO доступен без ключа и возвращает подготовленные ответы только для точного текста учебных сообщений из `src/data/demo.ts`. Изменённый текст не анализируется заглушкой. LIVE не импортирует этот набор: код провайдеров разделён, DEMO загружается только при выбранном режиме DEMO.

LIVE использует серверный `POST {AI_BASE_URL}/chat/completions`, Bearer-авторизацию, `messages`, `response_format: {type: "json_object"}` и `max_completion_tokens: 3000`. Это документированный формат [Chat Completions OpenAI](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). JSON mode выбран для совместимых API: он не гарантирует соответствие схеме, поэтому результат дополнительно проверяется Zod, а цитаты — наличием в сохранённом тексте. Ограничения режима описаны в [документации structured outputs](https://developers.openai.com/api/docs/guides/structured-outputs).

Настройки только в серверном `.env`:

```dotenv
AI_MODE=LIVE
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=
AI_MODEL=
```

Заполните ключ и идентификатор модели, доступной вашему аккаунту и поддерживающей Chat Completions JSON mode. Доступная модель автоматически не предполагается. Для другого совместимого провайдера укажите его документированный base URL; ключ отправляется только этому серверному адресу. HTTPS обязателен, кроме локального API на localhost. В HTTP-параметрах приложения нельзя заменить адрес провайдера. URL из исходных сообщений никогда не загружаются.

Проверка соединения выполняет один пробный разбор небольшого учебного текста. Успех означает ответ API, прошедший схему и проверку цитат, а не доказанное качество модели. Статус «настроен» означает лишь наличие допустимых настроек. При отсутствии ключа, недоступной модели, отказе, неверном JSON или непроверенной цитате возвращается видимая ошибка без перехода в DEMO. На настоящий LIVE-вызов без доступного ключа проверка не заявляется.

Вызов ограничен 16000 символами исходного текста и общим таймаутом 20 секунд. Допускается один повтор только после HTTP 429/503, задержка не больше двух секунд. Ответ ограничен 128 КБ. При ошибках тело ответа провайдера и детали сетевого исключения не показываются: они могут содержать чувствительные данные. В сервисный журнал передаются mode, model, durationMs, результат или безопасный код ошибки; ключ и скрытые рассуждения не сохраняются.

Сообщения передаются отдельно как недоверенные данные; каталог точек в запрос не включается. Координаты допустимы только если численно присутствуют в цитате. Для неизвестного места, времени и маршрута модель должна вернуть null. Даты «сегодня/завтра/вчера/послезавтра» сверяются с календарным днём публикации в её часовом поясе; при отсутствии этих метаданных остаются неизвестными. Совпадение цитаты само по себе не доказывает её истинность: применимость оценивает доменная логика, сведения подтверждает сотрудник.

`tests/unit/ai.test.ts` использует отдельный mock transport. Он проверяет ошибки, ограничения, цитаты, относительные даты и отсутствие fallback. Эти тесты не делают внешних запросов и не являются оценкой LIVE-модели. Эталонные ответы тестов не включаются в реальный запрос.
