# Показ за 3–5 минут

Открыть http://localhost:3000 после запуска по README. В настройках показать DEMO и фиксированные часы **14 ноября 2026, 09:00 Europe/Moscow**. Все названия, адреса, координаты и события учебные. Если база уже использовалась, не сбрасывайте собственные задачи ради показа; кнопка загрузки примеров воспроизводима.

1. **Точки — 30 секунд.** Открыть «У Арены»: учебные координаты, радиус 1000 м, вечерние часы. Показать рядом «Ранний кофе» с доставкой 07:00–08:00. Неизвестные координаты и пустой маршрут допустимы, но требуют уточнения.
2. **Концерт — 45 секунд.** В очереди открыть концерт 15 ноября 19:00–22:30. Сопоставить источник/цитату, рассчитанное расстояние около 650 м и часы работы. Предложение — проверить вечернюю смену и запас. Посетители и продажи неизвестны.
3. **Перекрытие — 45 секунд.** Открыть ограничение 16 ноября 09:00–13:00. Для маршрута по Учебной улице с доставкой 10:00–11:00 есть совпадение; доставка до 08:00 не пересекается. Ограничение автомобилей не доказывает снижение пешеходного спроса.
4. **Вода → задача → решение — 90 секунд.** Открыть отключение воды 16 ноября 08:00–12:00. Проверить точный дом/корпус пекарни и цитату. Подтвердить сведения, создать задачу ответственному со сроком и действием «Проверить резерв воды и согласовать план работы». Перевести в работу, затем завершить с решением и объяснением. Это ручное действие, не автоматическое закрытие точки. Показать запись в истории и её сохранность после обновления страницы.
5. **Обновления и пределы — 30 секунд.** Показать перенос ярмарки, отмену и неизвестное место. У изменившегося события прежнее решение требует повторной проверки. Показать явную маркировку DEMO и отсутствие подключённого автоматического мониторинга.

Дополнительная проверка сохранности: перезапустить приложение (`docker compose restart app` либо остановить и снова запустить `npm run dev`), найти задачу и решение в истории. Перезапуск не сбрасывает PostgreSQL.

Для полного сценария нового текста переключить сервер на LIVE по README и изменить известный пример. Сначала проверить соединение, затем импортировать новый текст и выполнить разбор. Обсудить цитаты и неизвестные поля, не только заголовок. Реальный LIVE показывать только после фактической проверки с доступным аккаунтом.

Честный резерв без API — подготовленные учебные сообщения с надписью «Демонстрационный режим — ответ подготовлен заранее». Не называть этот показ работающей нейросетью. В DEMO незнакомый текст должен показать ограничение. Ошибка LIVE не заменяется подготовленным ответом.

Визуальную и клавиатурную приёмку проводить на 320/768/1440 px. Скриншот, unit-тест или наличие кнопки сами по себе не доказывают полный пользовательский путь: результаты фактических проверок перечислены в `progress.md`.
