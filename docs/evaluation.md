# Независимая оценка извлечения

В `tests/evaluation/cases.json` семь синтетических сообщений, отличных от DEMO-ответов: перефразированное перекрытие, другой корпус, неизвестные координаты, отмена, относительное время без метаданных, одноимённая улица другого города и ключевые слова в названии книги.

Для воспроизведения:

```sh
npx tsx scripts/evaluate-ai.ts
# С настоящим серверным ключом, доступной моделью и base URL:
npx tsx scripts/evaluate-ai.ts --live
```

Без `--live` выполняется только простой поиск по ключевым словам; LIVE явно имеет результат `NOT_RUN`. С `--live` каждый новый текст отправляется реальному провайдеру через рабочий адаптер. Эталонные ответы `expected`, профиль тестовой точки и соседние примеры в запрос не включаются. Возможны до семи платных вызовов и по одному повтору при 429/503: запускать только с разрешённым аккаунтом.

Отдельно выводятся поиск кандидата, категория, применимость и результаты отдельных условий. Поиск по словам определяет только кандидат/категорию: отсутствие у него проверки условий помечено `NOT_ASSESSED`. Нет вымышленных процентов точности. JSON-отчёт содержит фактическое время запуска, режим, модель, длительность и безопасные ошибки без ключей. Сбой API не подменяется ответом DEMO и завершает команду с ненулевым кодом.

Выполнено **14 ноября 2026, 16:48:07 UTC (19:48:07 МСК)**, Node.js 24.22.3: baseline верно нашёл кандидата в **3 из 7** примеров и определил категорию в **3 из 7**. Условия он не оценивает. Это результат конкретного малого набора, не заявленная точность продукта.

| Пример | Baseline | Результат относительно эталона |
|---|---|---|
| Перефразированное перекрытие | Не найдено | Пропуск кандидата |
| Вода, другой корпус | Не найдено | Пропуск кандидата |
| Музыкальный вечер, место неизвестно | Не найдено | Пропуск кандидата |
| Отменённый концерт | Мероприятие | Категория верна; отмена не проверяется |
| Завтра, дата публикации неизвестна | Перекрытие | Категория верна; время не проверяется |
| Одноимённая улица другого города | Перекрытие | Категория верна; город не проверяется |
| Ключевые слова в названии книги | Отключение воды | Ложный кандидат |

LIVE в этом запуске: **NOT_RUN** для всех семи примеров. Сравнение качества модели пока не выполнено; mock unit-тесты не заменяют его. Документация интеграции и официальные API-ссылки: [ai.md](ai.md).
