# Источники и происхождение данных

Рабочие способы получения: ручной текст, документированный JSON-импорт, публичный Telegram-канал [@newsssss09](https://t.me/newsssss09) и локальный учебный набор. Telegram обновляется по кнопке; автоматический мониторинг, RSS, интеграции NMH и закрытые базы не подключены. «Последнее получение» — время сохранённого сообщения, а не обещание полного мониторинга города. При ошибке разбора успешное получение и успешный AI-анализ различаются.

Учебные исходники и подготовленные ответы находятся в `src/data/demo.ts`, CSV точек — в `src/data/demo-locations.csv`. Всего 14 исходных сообщений и 3 точки; дубликаты и версии означают, что число самостоятельных событий может быть меньше. Названия, адреса, координаты, компании и сообщения вымышлены. Вымышленный издатель подписан как учебный; реальных логотипов и придуманных ссылок редакций нет. Учебные координаты не являются результатом геокодирования адресов.

Сообщение хранит publisher, URL при наличии, publishedAt, timezone, receivedAt, способ получения и исходный текст. Версии содержат хеш текста/отпечаток сообщения; одинаковый повтор не создаёт новые задачи. Новая версия условий обнуляет прежнее подтверждение и требует пересмотра решения, сохраняя историю. Дата публикации не заменяет период события. Перепечатки группируются человеком как возможные связанные источники и не становятся независимыми подтверждениями.

Ввод URL не делает пользовательское сообщение официальным. Приложение не получает URL из текста и не сканирует произвольные адреса. Telegram-импорт обращается только к серверному адресу `https://t.me/s/newsssss09`, без перенаправлений; клиент не может заменить канал или URL. Остальные HTTP(S)-ссылки открываются пользователем отдельно. LIVE API задаётся только доверенной серверной конфигурацией; это отдельное соединение с моделью.

## Telegram

В «Событиях и источниках» откройте «Добавить сообщение» → «Telegram» → «Получить сообщения Telegram». Источник `@newsssss09` уже настроен. Импорт получает до 10 последних доступных текстовых публикаций, сохраняет исходный текст, издателя, дату публикации и ссылку на конкретный пост. Изображения без текста пропускаются. После получения запустите разбор в карточке события; происхождение сохраняется как `telegram`, а повторный импорт одинакового поста не создаёт новую карточку.

`GET /api/sources/telegram` возвращает настроенный источник и `monitoring:false`. `POST /api/sources/telegram/import` принимает `{ "actor": "Анна", "limit": 10 }`; `limit` от 1 до 20. Ответ содержит `fetched`, `imported`, `duplicates`, `skipped` и `results` с `eventId`/`duplicate`. При сетевой ошибке, закрытом канале, изменении формата страницы или частичной ошибке сохранения API показывает явную ошибку. Уже сохранённые записи остаются; импорт можно повторить.

Telegram должен быть доступен серверу по HTTPS. Бот и учётная запись Telegram не требуются; закрытые каналы не поддерживаются. Страница ограничена 2 МБ и таймаутом 15 секунд. Дата публикации берётся из `datetime` Telegram; локальный часовой пояс автора не предполагается (`timezone:null`), поэтому относительные даты события без дополнительных сведений требуют уточнения. Публичный просмотр не является полным архивом канала и не подтверждает достоверность новости.

Парсер и импорт проверяются в `tests/unit/telegram.test.ts` на локальных ответах транспорта, включая дубли, HTML-сущности и явные ошибки. 15 ноября 2026 на Node 24 выполнена реальная загрузка `t.me`: в локальную БД сохранены 10 текстовых публикаций `@newsssss09` со ссылками и датами; запись без подходящего текста пропущена. Соединение с Telegram в текущей среде нестабильно: отдельные попытки завершаются видимой сетевой ошибкой. AI-разбор при импорте не запускается.

## JSON-импорт

`POST /api/messages/import`, `Content-Type: application/json`:

```json
{
  "actor": "Менеджер локальной сессии",
  "messages": [
    {
      "text": "Учебное сообщение. Москва: мероприятие запланировано на 15 ноября 2026, 19:00–21:00, Europe/Moscow. Место пока неизвестно.",
      "publisher": "Мой учебный источник",
      "url": null,
      "publishedAt": "2026-11-14T08:00:00+03:00",
      "timezone": "Europe/Moscow"
    }
  ]
}
```

Пределы: до 50 сообщений в пакете, тело HTTP около 1 МБ, текст сообщения 10–20000 символов; AI принимает не больше 16000 символов на разбор. Дата — ISO 8601 с явным смещением; неизвестные publishedAt/timezone передаются как null. Origin назначается сервером `json`; клиент не может превратить запись в учебную/официальную подменой происхождения. Для явного обновления существующего события добавьте его внутренний `eventId`. Без него сообщения не объединяются на основании похожего заголовка.

Каждая строка пакета сохраняется атомарно. Ответ содержит `results` с номером строки, eventId/duplicate либо ошибкой и число `imported`. Частичная ошибка явная; можно повторить пакет после исправления. Импорт сохраняет сообщение, разбор запускается отдельно через карточку или `POST /api/events/{eventId}/analyze` с `{ "actor": "Менеджер локальной сессии" }`.

В DEMO приведённый новый текст намеренно не имеет подготовленного ответа: ограничение показывается пользователю. Для полного нового текста нужен LIVE. Для показа без ключа используйте точные исходники из `src/data/demo.ts` или загруженные учебные события. Неподтверждённые цитаты отвергаются; точная цитата доказывает происхождение фразы, а не истинность утверждения.

Технические первоисточники, проверенные при разработке: [Next.js installation](https://nextjs.org/docs/app/getting-started/installation), [Prisma PostgreSQL](https://www.prisma.io/docs/orm/overview/databases/postgresql), [Tailwind Next.js](https://tailwindcss.com/docs/installation/framework-guides/nextjs), [shadcn Next.js](https://ui.shadcn.com/docs/installation/next), [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create). Они описывают технологии; источниками реальных городских событий для демо не являются.
