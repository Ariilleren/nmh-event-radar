# Визуальная система

Рабочая задача: быстро увидеть точку, событие, период, основание и следующий шаг. Главная страница «Что требует решения» содержит очередь действий и спокойную контекстную колонку. Страница события разделяет факт из источника, применимость и предложение действия.

| Токен | Значение / назначение |
|---|---|
| Фон | `#F4F2EC`, тёплый нейтральный |
| Поверхность | `#FFFFFF` |
| Основной текст | `#182B30` |
| Боковая панель | `#102C30`, около 216 px на desktop |
| Основной акцент | `#147D73`; hover `#10665E` |
| Предупреждение | `#D8892C` с тёмной подписью, без мелкого белого текста |
| Риск | `#B24A44`, сопровождается подписью |
| Границы | `#E2E6DF`, input `#D6DDD6` |
| Радиусы | 12 px для кнопок, 16 px для поверхностей |
| Ритм | Основной шаг 8 px; плотные controls и служебные подписи используют меньшие шаги |
| Текст | Основной 14–16 px, адаптивные заголовки около 28–34 px; время и числа tabular |
| Шрифты | `Golos Text`, `Manrope`, затем `Segoe UI`, Arial, sans-serif; запуск не загружает шрифты из сети, используется доступный системный fallback |

Базовые компоненты находятся в `src/components/ui`: Button, Card, Input, Badge. Их варианты используются во всех экранах. Цветовые статусы всегда имеют текст; неизвестное условие не получает зелёного подтверждения. Главный CTA соответствует текущему шагу: создать задачу или запросить уточнение.

У полей есть подписи и видимый focus. Ошибка показывается с текстом, loading блокирует повторную операцию, пустая очередь объясняет следующие действия. Переполнения ограничиваются внутри таблиц/длинных текстов, без горизонтальной прокрутки всей страницы. На малой ширине формы переходят в одну колонку. `prefers-reduced-motion` отключает заметные переходы.

Обязательная матрица визуальной приёмки — 320, 768 и 1440 px: очередь, подробности события, форма точки, источники, задача и настройки. Проверять видимый focus, клавиатурный путь, цитаты, длинные названия, диалоги ошибок и работу без фоновой карты. Реальные результаты просмотра скриншотов фиксируются в `progress.md`; этот документ задаёт систему, не заменяет визуальную проверку.

Карта не используется: координаты служат расчёту расстояния в доменной логике, контекст показывает список и основания. Фиктивных графиков выручки, процентов уверенности или нарисованной «точной географии» нет.
