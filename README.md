# Радар бизнеса

События вокруг ваших точек и понятные действия для бизнеса. Приложение получает публикации из Telegram, сопоставляет их с адресами и процессами компании и сохраняет рекомендации Gemini. На главной — советы, в уведомлениях — новости, на карте — события с известным местом.

## Запуск для судей

Нужны **Node.js 24**, **PostgreSQL 17**, доступ в интернет и ключ **Gemini API**. Ключ передаётся отдельно или используется собственный; в репозитории его нет. Приложение проверено с `gemini-3.1-flash-lite`.

```sh
git clone https://github.com/Ariilleren/nmh-event-radar.git
cd nmh-event-radar
```

Скопируйте `.env.example` в `.env`:

```powershell
Copy-Item .env.example .env
```

На macOS/Linux: `cp .env.example .env`.

Откройте `.env`, вставьте значение `GEMINI_API_KEY` и проверьте `DATABASE_URL`. Для PostgreSQL из `compose.yaml` настройки БД уже заполнены. Если PostgreSQL не установлен, его можно запустить через Docker:

```sh
docker compose up -d db
```

При использовании своей PostgreSQL укажите URL своей пустой базы. Выбранные настройки анализа:

```dotenv
NEWS_AI_PROVIDER="gemini"
GEMINI_API_KEY="ВАШ_КЛЮЧ"
GEMINI_MODEL="gemini-3.1-flash-lite"
RADAR_DEMO_MODE="false"
RADAR_SYNC_ENABLED="true"
```

В каталоге проекта выполните:

```sh
npm ci
npm run db:migrate
node --import tsx scripts/setup-showcase.mjs --apply --analyze
npm run build
npm start
```

Подготовка загружает доступные публикации канала, создаёт профиль **Анны Соколовой**, компанию **«Три чашки»** и три точки, затем запускает настоящую обработку четырёх сообщений Gemini. Дождитесь завершения команды: она выведет число сохранённых рекомендаций. Повторный запуск не создаёт дубли. При ошибке Google/Telegram команда сообщит о ней; готовые ответы вместо модели не подставляются.

Откройте **http://localhost:3000/login**. Email: **anna@threecups.example**. Случайный пароль находится в локальном файле **`.local/showcase-credentials.json`**. Его можно открыть в редакторе. Файл не входит в Git; на каждом новом компьютере создаётся свой пароль.

Если порт 3000 занят: `npm start -- --port 3001`, затем http://localhost:3001/login.

## Что показать

1. **Профиль:** три точки — «Парк», «Офисы», «Вокзал». У каждой свои часы работы и окно поставки. У «Парка» маршрут проходит по Учебной улице; у «Офисов» есть зависимость от воды.
2. **Главная:** подготовка «Парка» к фестивалю, изменение поставки из-за перекрытия, режим работы «Офисов» при отключении воды. У каждой карточки — затронутая точка, действие и ссылка на исходную публикацию.
3. **Карта:** наведение или фокус на метке открывает новость; неизвестные координаты не подставляются.
4. **Уведомления:** все полученные новости и объяснение риска/возможности. Фестиваль в другом городе не создаёт совет для московских точек; «Вокзал» не затронут основным сценарием.

Демонстрационный сценарий использует вымышленные события, опубликованные с явной пометкой в [канале @newsssss09](https://t.me/newsssss09): [фестиваль](https://t.me/newsssss09/22), [перекрытие](https://t.me/newsssss09/25), [отключение воды](https://t.me/newsssss09/23), [другой город](https://t.me/newsssss09/24). Ответы получает настоящий Gemini, а не fixture. Имена и профиль оформлены как обычный продуктовый интерфейс.

**Даты основного сценария — 16 ноября 2026 года, Москва.** После окончания события активный совет перестаёт отображаться. Для показа в другой день владелец канала должен обновить даты этих публикаций; приложение получит новую версию и пересчитает анализ. Не изменяйте часы компьютера ради показа.

## Если советы ещё не появились

Проверьте ключ Gemini, соединение с PostgreSQL и доступ к публичному Telegram. При 429/временной ошибке Google приложение показывает статус и время повтора; сохранённые карточки остаются доступны. Открытие главной не тратит квоту — она читает результат из базы. После изменения `.env` перезапустите сервер.

Для сервера, работающего через прокси, поддерживаются стандартные `HTTPS_PROXY`, `HTTP_PROXY`, `NO_PROXY`. Карта и определение адреса требуют доступа к OpenStreetMap.

```sh
npm test
npm run test:integration
npm run lint
npm run build
```

Интеграционные и браузерные тесты требуют отдельной `TEST_DATABASE_URL` с именем базы, оканчивающимся на `_test`. Не направляйте их в рабочую БД.
