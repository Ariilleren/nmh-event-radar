# Радар бизнеса

**События вокруг ваших точек · Продуктовая концепция NMH**

Локальный кабинет операционного менеджера небольшой сети кофеен/пекарен: точка → сообщение → разбор → применимость с доказательствами → задача → решение и история. Поддерживаются мероприятия, ограничения движения и плановые отключения воды. Данные хранятся в PostgreSQL. Приложение не обещает безопасность или рост выручки и не отправляет сообщения за бизнес.

## Запуск с Docker

Нужны Docker Engine/Desktop с Compose и свободные порты 3000/5432. В каталоге проекта:

```sh
cp .env.example .env
docker compose up --build
```

В PowerShell вместо `cp` можно использовать `Copy-Item .env.example .env`. Открыть **http://localhost:3000**. Compose публикует порты на 127.0.0.1, ждёт healthcheck PostgreSQL, применяет миграции и заполняет только пустую базу. Повторный запуск сохраняет ваши записи. `docker compose down` останавливает проект с сохранением volume; для обычной остановки не добавляйте `-v`.

В `.env.example` учебный пароль локальной БД, не настоящий секрет. При его изменении до первого запуска согласуйте `POSTGRES_PASSWORD` и пароль в хостовых DATABASE_URL/TEST_DATABASE_URL. Уже созданный volume не меняет пароль автоматически.

## Разработка на хосте

Нужен Node.js **24.22.3 LTS** (ветка 24), npm и PostgreSQL; база может работать в Docker:

```sh
cp .env.example .env
docker compose up -d db
npm ci
npm run db:migrate
npm run db:seed
npm run dev
```

Адрес: http://localhost:3000. На хосте `DATABASE_URL` использует `127.0.0.1:5432`; внутри Compose приложение получает URL с именем сервиса `db:5432`. `npm run build` создаёт production-сборку; `npm start` запускает её на localhost. Production-сборка не требует ключа AI.

## DEMO и LIVE

По умолчанию `AI_MODE=DEMO`: **«Демонстрационный режим — ответ подготовлен заранее»**. Подготовлены 3 вымышленные точки и 14 исходных учебных сообщений, включая дубликат, неизвестные условия, перенос и отмену. Демо-часы — **14 ноября 2026, 09:00 Europe/Moscow**. Режим настоящих часов включается в настройках.

Для нового текста укажите на сервере:

```dotenv
AI_MODE=LIVE
AI_BASE_URL=https://api.openai.com/v1
AI_API_KEY=
AI_MODEL=
```

Заполните ключ и доступную вашему аккаунту модель с поддержкой Chat Completions JSON mode, перезапустите приложение и нажмите проверку соединения в настройках. Docker после правки `.env`: `docker compose up -d --force-recreate app`. Модель не выбрана автоматически. Ошибка LIVE остаётся ошибкой, fallback на DEMO отсутствует. Детали, лимиты и документация API: [docs/ai.md](docs/ai.md).

## Импорт и ежедневный сценарий

В разделе «Точки» скачайте шаблон CSV, загрузите файл, проверьте предпросмотр и исправьте ошибки строк. Поддерживаются UTF-8/BOM, `,` и `;`, до 500 строк и 1 МБ. `locationId` хранится строкой с ведущими нулями. Повтор по идентификатору обновляет запись, пустые ячейки не стирают старые значения. Для новой точки укажите timezone явно. Часы работы, окна доставки и улицы маршрута задаются формой; сложные поля CSV не поддерживает. Учебный CSV: `src/data/demo-locations.csv`.

Добавьте текст в «Источниках», разберите его, откройте событие и сопоставьте источник, применимость и предложение действия. Неизвестные условия требуют уточнения. Создайте задачу, назначьте срок/ответственного и завершите её с решением и объяснением. Изменение источника или точки помечает старые решения для повторной проверки. [Показ за 3–5 минут](docs/demo.md); [JSON-импорт и происхождение сообщений](docs/sources.md).

Выбранное имя участника — подпись локальной сессии, а не аутентифицированная личность. Сброс в настройках требует фразы `СБРОСИТЬ ДЕМО` и удаляет только учебные записи; связанные пользовательские задачи и изменённые пользователем данные сохраняются.

## Если запуск не удался

- БД недоступна: проверьте `docker compose ps`, `docker compose logs db`, пароль и правильный hostname в DATABASE_URL. Хостовое приложение не использует имя `db`.
- Порт занят: остановите свой предыдущий экземпляр или измените host-порт Compose и соответствующий URL. Не удаляйте чужие volumes.
- После обновления схемы: выполните `npm ci` и `npm run db:migrate`; данные не сбрасываются этой командой.
- DEMO не знает текст: выберите точный учебный пример или настройте LIVE. Это ожидаемое ограничение подготовленных ответов.
- LIVE выдаёт 401/403/404/429: проверьте серверный ключ, доступ модели, base URL и квоту. Не вставляйте ключ в браузер, исходники, скриншоты или Git.

Технологии и версии закреплены в package.json/package-lock.json; Prisma 7 использует адаптер PostgreSQL, Tailwind 4 — PostCSS. [Концепция](docs/product.md), [дизайн](docs/design.md), [источники](docs/sources.md).
